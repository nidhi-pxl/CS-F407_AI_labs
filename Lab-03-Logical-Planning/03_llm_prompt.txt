- a name
- positive preconditions
- negative preconditions
- positive effects
- negative effects

the current state.

When an action is applied:
1. remove its negative effects from the state;
2. add its positive effects to the state.

Use breadth-first search to find a sequence of actions that achieves
a specified goal.

The program should also:
- detect when no plan exists;
- print the resulting sequence of actions;
- print the states reached after each action.

{
    At(Robot,A),
    At(Package,A)
}

Goal:
{
    At(Package,C)

A <-> B
B <-> C

Precondition:
    At(Robot,X)

    At(Robot,Y)

    At(Robot,X)

PickUp(Package,X):
Preconditions:
    At(Robot,X)
    At(Package,X)

    Holding(Package)
Negative effect:
    At(Package,X)

Drop(Package,X):
Preconditions:
    At(Robot,X)
    Holding(Package)

    At(Package,X)
Negative effect:
    Holding(Package)

Generate the Python program and explain the implementation.
